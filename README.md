# Mega CRUD Fest

**Mega CRUD Fest** is the front door for a collection of thirty-two small web projects by `rutaabali3`. They are not trying to be one giant product. They are a shelf: a cellar, a watchlist, a planner, a tracker, a vault, a few quiet helpers, and several places to put the things that otherwise end up in a loose note somewhere.

Open [`index.html`](./index.html) for the collection’s hand-built landing page. Each project card points to its original live GitHub Pages site.

## The collection

The projects cover media, health, habits, home management, learning, planning, personal organization, and creative work. The index includes a small search box so the collection remains useful once the names start blending together.

## Live hub

The intended public entry point is the GitHub Pages site for this repository:

`https://rutaabali3.github.io/mega-crud-fest/`

The original project repositories remain the canonical destinations until the collection has been verified and the owner confirms the final deletion step.
